Shadow Hunters — Rules

Number of Players: 4 to 8 — Play Time: 30–45 min

Rules written by Max Levatich — Found a bug? Report it here.

Overview

Shadow Hunters is an online multiplayer game (based on the board game) in which identities are hidden and players must discover allies and enemies.

How to Start a Game

Enter a username and room on the main page – clicking Join takes you to the waiting room where you can chat with other players. Select the desired number of players then click "Start Game".

Gameplay Basics

Each player receives a character and an allegiance. During your turn you can move, attack, or use special abilities. Use the UI buttons in the game room to perform actions. The game continues until a win condition is met.

Tips

  • Use short, clear chat messages to coordinate.
  • If you disconnect, re-enter the same username and room to reconnect (if the game allows reconnections).
  • Names starting with "CPU" are reserved for computer players.
